# C1F1 — BROWSER RUNTIME ERRORS

Authenticated deployed browser runtime was **not executed** in this environment.

Therefore the following must not be reported as zero:

- unexpected console.error: NOT MEASURED
- uncaught exception: NOT MEASURED
- unhandledrejection: NOT MEASURED
- duplicate listener symptom: NOT MEASURED
- duplicate primary transaction: NOT MEASURED AUTHENTICATED (synthetic command tests PASS)
- receipt modal unexpected close: NOT MEASURED

Injected/synthetic secondary failure tests are handled and classified, but they do not substitute for authenticated browser evidence.
